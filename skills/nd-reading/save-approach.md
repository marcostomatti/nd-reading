# Keeping what works

Read when the reader picks a format in a format check, says a format helped ("this works", "keep doing this"), or makes the same choice twice. The core rules still apply.

1. **Offer to keep it.** Name the kind of content and the format: "Should I use a small diagram by default for processes that branch?" When a format check is still open, the offer can ride on the same question.
2. **Save only after a yes.** Record four things: the kind of content (the trigger), the chosen format, a one-line example, and the date. Save it where the harness keeps lasting preferences, such as its memory. If it has none, ask whether to add it to the reader's instructions file for the project.
3. **Offer a new module for a new approach.** When the approach covers a scenario or a tool this skill does not have, offer to write it into the skill as a module with its trigger. The reader decides.
4. **Use it next time.** When the trigger fires again, use the saved format without asking. When two saved preferences conflict, ask once which one wins, and update the record.
